# Chat Server/Client Program

This is a chat server/client application built with C# that allows clients to connect and send messages to each other.

## Requirements

- Windows operating system (The program is compiled as a `.exe` file)
- .NET Framework 4.7.2 or later (if running from source)
  
## How to Run

1. Download the `Server.exe` and `Client.exe`  file from the release folder.
2. Double-click on the `Server.exe` file to start the server.
3. The server will automatically start listening for incoming connections.
4. Double-click on the `Client.exe` file to start the client.

## Notes

- Make sure the server is allowed through your firewall on port 65432.
